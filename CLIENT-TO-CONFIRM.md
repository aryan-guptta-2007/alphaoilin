# Claims Removed for Client Verification

This document lists every marketing claim, certification, statistic, and superlative removed from the website prior to deployment. If any of these claims are factually true and supported by documentation (e.g., certificates, official trading records, or licensing), please provide proof so we can reinstate them.

- **Verification Needed**: Official ISO 9001 certificate copy, accreditation number, and issuing body.

### Claim: `"Accredited regional refineries"` & `"Accredited inspection agencies"`
